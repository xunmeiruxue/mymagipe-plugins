百度网盘 正在连接 magpie…

这个插件把百度网盘 MCP 的工具接到 magpie。填写一次，之后 token 由它自己续。

现在的情况

  • 读取中…

保存或登录之后 magpie 会重启一次插件宿主，工具大约几秒后出现在「资源库 › MCP 服务器」里。

应用凭证

在「百度网盘开放平台 › 应用详情 › 应用凭证」里：AppKey 就是 client_id，SecretKey 就是 client_secret（AppID 不用，SignKey 也无关）。

授权一次

点「生成链接」，在浏览器里打开并扫码；百度会停在它的页面上，把页面显示的 code（或地址栏里 code=… 的值）粘回下面。code 只能用一次、10 分钟内有效。
